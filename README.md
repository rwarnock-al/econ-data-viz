# econ-data-viz

Interactive charts for Apartment List research reports, served via GitHub Pages.

**This repo is public.** Commit only finished HTML/JS and shared assets — no raw data, SQL, `.Rmd`, or drafts (see `.gitignore`).

Each chart is a self-contained HTML file at the repo root, published at:

    https://rwarnock-al.github.io/econ-data-viz/<chart-name>.html

Embed in a report with:

    <iframe src="https://rwarnock-al.github.io/econ-data-viz/<chart-name>.html" width="775" height="575" scrolling="no"></iframe>

To update a chart: edit, commit, push. Pages redeploys in ~1 minute; embedded iframes pick it up automatically.
